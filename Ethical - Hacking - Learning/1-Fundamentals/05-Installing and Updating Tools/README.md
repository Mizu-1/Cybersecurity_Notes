طريقة عمل تحديث لنظام كالي لينكس كامل مثل باقي انظمة التشغيل

> [!NOTE] sudo apt update && apt upgrade
> هم امرين في سطر واحد لربطهم اضافة علامتين اند(&&)
> فائدة هذا الامر هو تحديث قاعدة البيانات او الحزم في النظام

 في بعض الاحيان يجب ان يكون المستخدم root
 
> [!NOTE] sudo su -
> لتحويل المستخدم الى root

> [!NOTE] apt install (اسم الاداء)
> لتنزيل اداء معينة

> [!NOTE] sudo git clone (رابط ملف التحميل)
> لتحميل ملف عبر رابط githup

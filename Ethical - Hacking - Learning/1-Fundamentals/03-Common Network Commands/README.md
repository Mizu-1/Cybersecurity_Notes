
هو تعريف للاموامر الموجودة وعملها وليس ضروري فهمها فقط التعرف عليها وسوف نتعمق فيها اكثر لاحقا

> [!NOTE] ip a
> يعرض الاتصالات الثابتة
> يعرض لك عنوان lookback و eth0 و ip address بالشكلين مع البرودكاست
> نفس امر ifconfig لكن عرضها بالطريقة الحديثة منظم وملون وواضح

> [!NOTE] iwconfig
> بعرض التصالات اللاسلكية
> 

> [!NOTE] ip n
> n = Neighbor
> بعرض جدول الجيران
> يعرض كل معلومات الاجهزة المجاورة في الشبكة
> ويتم استخدامة في :
> ARP = Address Resolution Protocol (arp -a)
> NDP = Neighbor Discovery Protocol
> عشان يساوي عناوين الip بالmacAddress


> [!NOTE] ip r - route
> r = Route
> بستخدم لعرض او تعديل جدول التوجيه
> بحتوي على معلومات الشبكة المتصلة والمسارات المستخدمة لتوجية حزم البيانات بين الشبكات

> [!NOTE] netstat
> بستخدم لعرض اخصائيات الشبكة ومعلومات الاتصالات وانظمة التشغيل
> بوفر لمحة عامة عن حالة الشبكة والمنافذ المفتوحة والاتصالات النشطة والاحصائيات المتعلقة بالاتصالات
> تشمل المعلومات على عناوين ip ومنافذ الاتصالات وحالة الاتصال
> بمكن استخدام معاملات اضافية معها لظهور تنائج ادق واوضح ومحددة

> [!NOTE] netstat -a
> يعرض التصالات النشطة وغير نشطة
> 

> [!NOTE] netstat -n
> لعرض عناوين الip ومنافذ الاتصالات بتنسيق وارقام

> [!NOTE] netstat -p
> لعرض البرامج المرتبطة بكل اتصال

القائمة (List) هي نوع من أنواع البيانات في Python، تُستخدم لتخزين مجموعة من العناصر داخل أقواس مربعة `[]`.

يمكن استدعاء جميع العناصر الموجودة في القائمة أو استخراج عنصر محدد باستخدام رقم الفهرس (Index).

```
names = ["mama", "mizu", "111", "baba"]

print(names)     # استدعاء القائمة كاملة
print(names[1])  # استدعاء العنصر الثاني
print (names[1:4]) # استدعاء العناصير من الثاني الى الرابع
print (names[1:]) # استدعاء العناصر من الثاني الى الاخير
print (names[:2]) # استدعاء العناصر حتى الوصل الى العنصر الثالث
print (names[-1]) # استدعاء اخر عنصر
print (len(names)) # يحسب عدد العناصر
names.append("test") # اضافة عنصر جديد
names.insert(3, "test2") # اضافة العنصر الجديد في اي موقع
names.pop() # يحذف اخر عنصر
names.pop(3) # يحذف العنصر الرابع
names[0] = mom # تعديل على العنصر الاول
```
**ملاحظات:**
- يبدأ ترقيم العناصر من الصفر `0`.
- الرقم `[1]` يشير إلى العنصر الثاني وليس الأول.
- يمكن أن تحتوي القائمة على أنواع مختلفة من البيانات.
- لدمج قائمتين نضيفهم في متغيير جديد
```
frind = [["ahmad" , 22] , ["ali" , 21] , ["osama" , 24]]
A = frind[0][1]
print (A)
```

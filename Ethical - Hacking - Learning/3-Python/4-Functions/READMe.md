الـ Functions (الدوال) هي مجموعة من الأوامر البرمجية التي نكتبها لتنفيذ مهمة معينة، ويمكننا استدعاؤها واستخدامها أكثر من مرة دون الحاجة إلى إعادة كتابة الكود


```
def aboutyou():
	name = "mizu"
	age = 23
	print ("my name is: " + name + " and my age is: str(age)") 
aboutyou()
```
هذا مثال على الدالة عبارة عن مجموعة من التعليمات البرمجية التي نضعها داخل كتلة مستقلة، ولا تُنفّذ هذه التعليمات إلا عندما نستدعي الدالة، ويمكن استدعاؤها أكثر من مرة.
```
def add(number):
	print (number + 200)
add(100)
```
  الباراميترز Parameters هي المتغيرات التي نضعها داخل أقواس الدالة عند تعريفها، حتى تستقبل معلومات من خارج الدالة وتستخدمها بداخلها.
```
  def addtownumber(num1,num2):
```

هذا مثال اخر للباراميترز
```
def multiply(num1,num2):
	return (num1 * num2)
multiply(2,2)
```
الريتورن return هو امر عكس الطباعة print هي تحفظ القيمة ويمكن ترجع قيمة من fumctions
```
def multiply2(num1,num2):
	result = num1 * num2
	return result
store = multiply2(2,2)
print (store +2)
```
هذا مثال يوضح اكثر ان اقدر اخزنها في متغير والمتغير اقدر استخدمه في اكثر من مكان خارج الدالة
والreturn يعتبر جزء اساسي في الدالة functions لاسترجاع استخدام الداخلة في مكان اخر

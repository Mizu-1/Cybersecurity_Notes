ال loop هو التكرار الين النهاية او انتهاء الامر
```
name = ["ali" , "mazen" , "mizu" , "ahmad"]
for x in name:
	print (x)
```
هذا مثال عليها لاستدعاء امر التكرار باستخدام كلمة for
الwhile فكرتها نفس الfor لكن كلما كان الشرط صحيح يكمل شغال
```
num = 1
while num < 10:
	print (num)
	num += 1
```
هذا مثال للwhile

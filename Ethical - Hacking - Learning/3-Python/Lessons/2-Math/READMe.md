درس اليوم تكلم عن الرياضيات في لغة بايثون 

> [!NOTE] print (100 + 100)
> هذه عملية الجمع

> [!NOTE] print (100 - 90)
> هذه عملية الطرح

> [!NOTE] print (100 * 100) 
> هذه عملية الضرب

> [!NOTE] print (100 / 100)
> هذه عملية القسمة

> [!NOTE] print (10 // 3)
> وهذه عملية القسمة بدون ظهور الارقام بعد الفاصل

> [!NOTE] print (13%2)
> هذه عملية باقي القسمة

> [!NOTE] print (10 ** 2) 
> هذه عملية الاسس

بايثون تتبع عملية الاولوية في الحسابات وهي :
( الاقواس - الضرب\القسمة - الجمع\الطرح )

> [!NOTE] print (6-5*2/2) # pemdas
> الاولوية

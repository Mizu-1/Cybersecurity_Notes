المتغيرات او variables هو متغير او شيء يمكن تغييره في الكود

> [!NOTE] username = "ali"
print (username)
> هذه هو المتغير طريقة تعريفة وطباعة

الميثود او methods هي اختصارات موجودة وجاهزة لتسهيل تعديل الكود 
- chanelname = "mizu111"
> [!NOTE] print (chanelname.upper())
> هذه احد methods وهي قلب الحروف من الصغيرة الى الكبيرة

> [!NOTE] print (chanelname.lower())
> هذه لقلب الحروف الى الحروف الصغيرة

> [!NOTE] print (chanelname.title())
> هذه لقلب اول حرق من كل كلمة فقط الى حروف كبيرة 

> [!NOTE] print (len(chanelname))
> هذه الامر لحساب عدد الحروف في المتغير

- name = "ahmed"
- age = 24 #integer
- degree = 49.5 #float
> [!NOTE] print (int(degree))
> هذه الامر يطبع الرقم صحيح بدون فواصل او يحول الرقم العشري الى رقم صحيح

> [!NOTE] print ("my name is: " + name + " and my age is: str(age)")
> هذه مثال لطريقة ربط النص مع المتغيرات واستخدام احدى الميثود وهو تحويل الرقم الى نص

> [!NOTE] age += 1
print (age)
> هذه مثال يوضح المتغيير كيف يمكن تغييره في اي وقت

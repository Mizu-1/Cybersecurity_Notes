
> [!NOTE] Host (مضيف)
> هو اي جهاز يتصل بالانترنت او يرسل و يستقبل بيانات مثل جهاز الكمبيوتر , لابتوب , جوال , طابعة , سيرفر

> [!NOTE]
> اي جهاز يرسل طلب بقع في فئة client واي جهاز يستقبل الطلبات بقع في فئة server

> [!NOTE] Server
> هو مثل جهاز كمبيوتر عادي مثبت عليه برنامج يخدم صفحات الويب

> [!NOTE] IP Address
> هو هوية لكل Host 
> يتكون من 32 Bit ويكون على شكل 01 ويتقسم الى اربع قطع ومحوله الى ارقام عشريه
> واقل رقم يمكن ان يكون هو 0 واكبر رقم هو 255

> [!NOTE] Network
> هي التي تقوم بنقل البيانات بين جهازين او بين 2 Hosts 
> في الواقع هي مجموعة من Hosts تحتاج الى اتصال بسيط
